# Gapura

Record where personal data flows when your app calls an LLM, then print a **cross-border transfer log** mapped to Article 161 of Indonesian Government Regulation 33/2026. Runs locally.

**A working note, not legal advice.** Not affiliated with PT Gapura Angkasa.

Masking companion: [@adindamochamad/tirai](https://github.com/adindamochamad/tirai).

## Requirements

- Node.js **≥ 20**
- npm

## Quick start

```bash
npm ci && npm run build && npm run demo
```

See [README.md](README.md) (Indonesian) for `wrapFetch`, `gapura report`, and limits.
