# Draf paragraf README Tirai (untuk repo Tirai — commit oleh Adinda)

**Bahasa Indonesia:**

> **Gapura** ([github.com/adindamochamad/gapura](https://github.com/adindamochamad/gapura)) — alat open source terpisah yang **mencatat** panggilan ke API LLM dan membuat lampiran Pasal 161 PP 33/2026. Tirai **menyamarkan** sebelum kirim; Gapura **mencatat** apakah penyamaran terlihat di request. Bukan pendapat hukum.

**English:**

> **Gapura** — a separate open-source tool that **records** LLM API calls and prints an Article 161 transfer log (Indonesia GR 33/2026). Tirai **masks** before send; Gapura **notes** whether masking appears on the wire. Not legal advice.
