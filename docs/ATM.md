# ATM — Amati, Tiru, Modifikasi

Dibuka ulang **28 Okt 2026 (WIB)** di browser. Pola dipakai; aset tidak disalin.

## Sumber yang ditiru sekarang

### Untitled UI v8 — [untitledui.com](https://www.untitledui.com/)
Dilihat: beranda kit + [React badges](https://www.untitledui.com/react/components/badges).

**Amati:** sans-serif sistem, skala abu (gray-50 halaman, kartu putih, border gray-200, radius 12–16px, bayangan `xs`), nav sticky, page header (badge + H1 besar + lede abu), kartu metrik berjajar, tabel dengan thead gray-50, accordion berbatas, badge kapsul dengan titik status. Merek kit: tombol **ungu** — **tidak ditiru**.

**Tiru:** `.nav` + `.feat` ikon, `.badge` kapsul, `.metrics` lima kartu, `.card` + tabel panggilan, Pasal 161 sebagai `<details>` bergaris.

**Modifikasi:** palet semantik hijau/merah/ambar Untitled, tanpa `brand-600` ungu; logo candi bentar; tanpa Google Fonts; file://; bukan dasbor compliance.
