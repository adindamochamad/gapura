# Batasan Gapura

- **`gapura proxy` eksperimental — jangan dijalankan di jaringan bersama.** Hanya untuk uji lokal sampai hardening selesai.
- Hanya melihat panggilan HTTP yang lewat **`wrapFetch`** (atau **`gapura proxy`** jika ada).
- **Mencatat dan mendeteksi** — tidak menjamin organisasi memenuhi kewajiban PDP.
- Tidak tahu lokasi pemrosesan **aktual** selain yang tertulis di dokumentasi penyedia (atau `belum terverifikasi`).
- Deteksi **berbasis aturan** Tirai, bukan ML; nama tanpa label tidak terdeteksi.
- **Respons API tidak diperiksa.**
- **Bukan nasihat hukum.**
- Pengawas PDP **belum terbentuk** (Sep 2026, sumber pers **[belum terverifikasi]** di README lengkap).
