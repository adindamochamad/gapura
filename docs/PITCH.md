# Pitch singkat Gapura

Pasal 161 PP 33/2026 mengatur langkah untuk transfer data pribadi ke luar wilayah. Gapura membantu mencatat panggilan LLM sebagai **catatan bantu**, bukan memenuhi kewajiban hukum.

Gapura adalah alat open source lokal yang **mencatat** panggilan ke API LLM: ke penyedia mana, jenis data apa (bukan isinya), dan apakah terlihat disamarkan. Output: kolom Pasal 161 a–g untuk diisi tim Anda. **Bukan nasihat hukum.**
