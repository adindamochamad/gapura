## Pasal 160 ayat (3) (konteks transfer)

Transfer Data Pribadi dilakukan jika pengendali **membuat Data Pribadi tersedia** bagi pengendali/prosesor penerima di luar wilayah hukum Indonesia (bukan hanya “mengirim file”).

## Pasal 161

Pengendali dan/atau prosesor **harus**:

| Butir | Kutipan (diringkas dari PP) | Label Gapura |
| --- | --- | --- |
| a | perekaman dan pemetaan siklus transfer dan implikasinya | sebagian |
| b | memastikan data cukup, relevan, terbatas sesuai tujuan transfer | sebagian |
| c | mengidentifikasi instrumen hukum rujukan | isi manual |
| d | penilaian efektivitas instrumen sebelum transfer | isi manual |

| g | evaluasi ulang berkala | sebagian |

## Pasal 162 ayat (2) huruf h

Format data yang ditransfer: teks biasa / **disamarkan** / dienkripsi — Gapura menampilkan status `raw` / `masked` / `mixed`, bukan enkripsi TLS.
